# ClaudeAI-widget-Useage
วิธีแจกจ่ายไปเครื่องอื่น: ก็อปโฟลเดอร์ claude-usage-widget ทั้งโฟลเดอร์ไปเครื่องปลายทาง (USB, แชร์ไฟล์, ฯลฯ) แล้วให้เครื่องนั้นดับเบิลคลิก setup.bat — ตัวสคริปต์จะไปอ่าน %USERPROFILE%\.claude\.credentials.json ของเครื่องนั้นเองอัตโนมัติ (ผ่าน Path.home() ในโค้ด ไม่ได้ผูกกับเครื่องนี้) จึงจะเชื่อมกับบัญชี Claude ที่ล็อกอินอยู่บนเครื่องนั้นโดยอัตโนมัติ ไม่ต้องแก้โค้ดอะไรเลย เงื่อนไขเดียวคือเครื่องปลายทางต้องเคยรัน claude login ไว้ก่อน และมี Python ติดตั้งอยู่
