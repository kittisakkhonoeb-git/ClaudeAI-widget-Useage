Claude Usage Widget
====================

Widget เล็ก ๆ ลอยมุมล่างขวาจอ แสดง % การใช้งาน Claude Code ของ "เครื่องนี้"
(session ปัจจุบัน / รายสัปดาห์ / เวลารีเซตครั้งถัดไป) ดึงข้อมูลจริงจากบัญชี
Claude ที่ล็อกอินอยู่บนเครื่องนั้น ๆ ผ่าน API ของ Anthropic โดยตรง

ก็อปโฟลเดอร์นี้ทั้งโฟลเดอร์ไปเครื่องไหนก็ได้ แล้วมันจะไปอ่าน login ของ
Claude Code ที่มีอยู่แล้วบนเครื่องนั้นเองอัตโนมัติ ไม่ต้องแก้โค้ดอะไรเลย


ข้อกำหนดก่อนใช้งาน (บนเครื่องปลายทาง)
--------------------------------------
1. ติดตั้ง Claude Code แล้ว และเคยรันคำสั่ง `claude` เพื่อ login อย่างน้อย
   1 ครั้ง (widget จะอ่าน token จากไฟล์ที่ Claude Code สร้างไว้ที่
   %USERPROFILE%\.claude\.credentials.json)
2. ติดตั้ง Python 3 (จาก https://python.org) โดยตอนติดตั้งให้ติ๊ก
   "Add python.exe to PATH" — ตัว Python ที่ติดตั้งจาก python.org จะมี
   tkinter มาให้อยู่แล้ว ไม่ต้อง pip install อะไรเพิ่ม


วิธีติดตั้ง
-----------
1. ก็อปโฟลเดอร์ "claude-usage-widget" ทั้งโฟลเดอร์ไปไว้ที่เครื่องปลายทาง
   (ตำแหน่งไหนก็ได้ เช่น Desktop หรือ Documents)
2. ดับเบิลคลิก setup.bat
   - จะเช็ค Python/tkinter ให้อัตโนมัติ
   - จะตั้งให้ widget เปิดเองทุกครั้งที่ล็อกอินเข้าเครื่อง (ผ่าน Startup folder)
   - จะเปิด widget ขึ้นมาให้ทันทีหลัง setup เสร็จ

หลังจากนั้นถ้าอยากเปิดเองอีกโดยไม่ต้องรัน setup.bat ใหม่ ให้ดับเบิลคลิก:
   Start Claude Usage Widget.vbs


วิธีถอนการติดตั้ง
------------------
ดับเบิลคลิก uninstall.bat — จะปิด widget และลบการเปิดอัตโนมัติตอน login
จากนั้นลบโฟลเดอร์นี้ทิ้งได้เลย


เกี่ยวกับความปลอดภัย
---------------------
- Widget อ่าน OAuth token จากไฟล์ .credentials.json ที่ Claude Code สร้างไว้
  บนเครื่องนั้นอยู่แล้ว (ไฟล์เดียวกับที่ตัว Claude Code CLI ใช้เอง)
- Token จะถูกใช้ยิง request ไปที่ api.anthropic.com และ
  platform.claude.com (สำหรับ auto-refresh token เมื่อใกล้หมดอายุ) เท่านั้น
  ไม่ถูกส่งไปที่อื่น และไม่ถูกเก็บ/แสดงที่ไหนเพิ่มเติม
- ทุกเครื่องที่ติดตั้งจะเห็นเฉพาะข้อมูลของบัญชีที่ล็อกอินอยู่บนเครื่องนั้น
  เท่านั้น ไม่มีการเชื่อมข้อมูลข้ามเครื่อง
- เมื่อ token ใกล้หมดอายุ (ภายใน 15 นาที) widget จะขอ token ใหม่และเขียน
  ทับกลับเข้าไฟล์ .credentials.json เดิมให้อัตโนมัติ (มีสำรองไฟล์เดิมไว้ที่
  .credentials.json.bak ทุกครั้งก่อนเขียนทับ)


การใช้งาน widget
-----------------
- ไอคอนวงกลมมุมล่างขวาจอ = ตัวเลข % การใช้งาน session ปัจจุบัน
  (สีเขียว/เหลือง/แดง ตามความรุนแรง)
- คลิกที่ไอคอน = เปิดแผงรายละเอียด (session / รายสัปดาห์ / เวลารีเซต)
- คลิกแถบหัวข้อในแผง = ยุบกลับเป็นไอคอน
- ปุ่ม ↻ ในแผง = รีเฟรชข้อมูลทันที
- ปุ่ม ✕ ในแผง = ปิดโปรแกรม
- ลากไอคอนหรือแผงเพื่อย้ายตำแหน่งได้
